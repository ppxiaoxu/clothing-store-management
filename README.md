# 童装店记货系统（Clothing Store Management System）

## 项目简介

童装店记货系统是一套面向中小型童装门店的进销存管理系统。

项目来源于真实业务需求，旨在解决传统门店依赖纸质记录、微信聊天记录统计库存效率低、商品管理混乱等问题，实现商品、库存、进货、销售等业务的数字化管理。

系统采用前后端分离架构开发，支持商品管理、库存管理、进货管理、销售统计等功能，并可部署至云服务器供手机和电脑访问。

## 数据库设计

### 商品分类（category）

用于维护商品分类信息。

### 进货商（supplier）

用于维护商品供应商信息。

### 商品（product）

记录商品基础信息：

* 商品名称
* 商品货号
* 适合年龄
* 性别
* 分类
* 供应商

### 商品规格（sku）

记录具体库存规格：

* 颜色
* 尺码
* 库存数量
* 进价
* 售价

### 进货记录（purchase_record）

记录每次进货行为：

* 进货商
* 商品
* 商品规格
* 进货数量
* 进货价格
* 进货时间
