# 🧸 童装店记货系统

> AI Coding 与工程化实践：结合 Matt Pocock 的六项工程 Skills，组织需求澄清、规格、任务拆分、测试、审查与排障。见 [使用与学习说明](docs/ai-coding/README.md)。

> 一个基于 **Spring Boot + Vue3** 开发的童装店进销存管理系统
> 从家里童装店真实业务场景出发，让记货、进货、销售、库存管理更加简单高效 ✨

---

## 📖 项目简介

小时候总觉得爸妈记账很简单：

```text
进了多少货
卖了多少件
赚了多少钱
```

后来才发现：

```text
😵 货太多记不住
😵 库存经常对不上
😵 哪个颜色卖得快不知道
😵 今天赚了多少钱要手算
```

于是利用课余时间开发了这套 **童装店记货系统**。

系统支持：

✅ 商品管理
✅ 进货管理
✅ 销售管理
✅ 库存自动增减
✅ 库存流水追踪
✅ 销售统计分析
✅ 商品图片上传（阿里云 OSS）

# 🌟 项目亮点

## 🔥 库存自动联动

传统记账：

```text
进货
↓
手动改库存

销售
↓
手动改库存
```

容易出错。

本系统：

```text
进货
↓
自动加库存

销售
↓
自动减库存
```

确保库存数据准确。

---

## 🔥 库存流水追踪

所有库存变化均生成流水记录。

真正做到：

```text
库存从哪里来
库存去了哪里
```

一目了然。

---
