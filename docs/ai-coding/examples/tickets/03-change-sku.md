# 03：更换销售规格时两边库存共同提交

Status: draft

Source: [销售更正规格草案](../sales-correction-spec.md)

**What to build:** 用户更正销售的颜色或尺码时，旧规格退回原数量，新规格扣减新数量；新规格不足时整笔更正失败，并能通过页面及查询接口观察结果。

**Blocked by:** None。本场景可独立验证；可复用 01、02 的经验但不需要它们的产物才能开始。

- [ ] 成功时两种 SKU 和关联流水反映各自变动。
- [ ] 新规格库存不足时，旧规格不会残留单独回补。
- [ ] 销售记录最终归属、数量、金额与页面一致。
- [ ] 记录本场景未覆盖并发交换、死锁重试和重复请求。

完成验收后，在任务下附环境、请求与实际输出，再更新状态。
