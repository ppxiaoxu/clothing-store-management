# 01：销售改少后正确退库

Status: draft

Source: [销售更正规格草案](../sales-correction-spec.md)

- [ ] 新增关联该销售的 +2 流水，前后值连续。
- [ ] 金额按后端规则重算，页面刷新结果一致。
- [ ] 验证输入、命令、实际输出及环境清理留有记录。
