# 02：销售改多时库存不足整体失败

Status: draft

Source: [销售更正规格草案](../sales-correction-spec.md)

**What to build:** 用户增加销售数量超过剩余库存时，页面收到明确提示，原销售、库存和流水均不留下部分变化；包括接口与真实事务行为的验证。

**Blocked by:** None。可独立验证失败路径，不因编号在后而虚构对 01 的依赖；启动前需具备隔离环境。

- [ ] 失败提示能表达库存不足。
- [ ] 销售数量和金额保留原值。
- [ ] 库存和关联流水未发生部分提交。
- [ ] 同时保留足够库存时更正成功的对照结果。

此样例没有发布远程 Issue，未批准实施，验收均未执行。
